## 1. 功能实验的共同约定

未来建立自检环境时，固定版本、初始化寄存器和内存、记录程序机器码与编译方式。使用非零且互异的旧值和期望值，结束点由测试协议定义，并加超时。记录每次有效 GPR 写入的 rd/data、内存写入地址／值、取指 PC 和必要控制；不能用“有 UART 输出”代替完整结果校验。

观察路径均在 student_top 的 u_RISCV_CORE 下，局部名可能随未来修改变化：id_ins_o、id_ins_addr_o、id_reg*_rd_addr_o、id_reg*_rd_data_o、ex_jump_flag_o、ex_jump_addr_o、ex_hold_flag_o、wb_reg_wr_en_o、wb_reg_wr_addr_o、wb_reg_wr_data_o；另记录 bridge 的地址与返回。不要把 NOP 对 x0 的写使能当作完成有效任务指令的通用计数器。

## 2. 可直接展开的实验规格

### V01 · ALU 链与最新值优先

- **输入：** addi x5,x0,1；addi x5,x5,1；add x6,x5,x5；sub x7,x6,x5。初始其他相关寄存器用不同已知值。
- **观察：** A gpr 选择、B ex/mbem/mem/wb_bypass；id_ex 采样的两个值；最终写回。
- **通过：** x5=2、x6=4、x7=2；多个来源命中时取较新的值。加入 0—3 个无关指令，分别覆盖各距离和两个读口。
- **意义：** 验证前递正确，而非仅证明 ALU 运算正确。

### V02 · 紧邻及双源 load-use

- **输入：** RAM[x10]=7、旧 x5=99、x7=3；分别运行 lw x5,0(x10) 后接 add x6,x5,x7 和 add x6,x5,x5。
- **观察：** A 两个比较位与 cu 分支；B load_use；jump/hold、重取 PC、消费者采样。
- **通过：** x6 分别为 10 和 14；后继只能按正确数据产生最终副作用。对当前 A 的双源例预期能暴露疑点，但本次未运行。
- **意义：** 重取式控制与漏掉 11 的覆盖问题；统计“多多少周期”必须同时给出无依赖对照。

### V03 · 隔一条与连续 load

- **输入：** lw x5,0(x10)；addi x8,x0,1；add x6,x5,x7。另测 lw x5,0(x10)；lw x6,4(x10)；add x7,x5,x6，内存分别为 7、11。
- **观察：** B reg_wr_addr_reg、is_load_o、load_any_use；每级 rd、返回数据与 PC。
- **通过：** 第一例读正确 x5；第二例 x7=18，无重复错误提交或跳错位置。延伸到 load 的结果作为下一条 load 的基地址。
- **意义：** 检查 BUFFER 增加后的依赖距离与反复重取。

### V04 · x0、无效源与暂停／冲刷重叠

- **输入：** load 写 x0 后接只读 x0 的合法指令；立即数指令与 load rd 在原始编码中出现假相等；另构造较老 EX 分支修正与 B load_any_use 同周期。
- **观察：** 解码后的有效源、x0 读值、jump_addr 选择、气泡的 PC／预测元数据。
- **通过：** x0 恒为 0、无错误重定向或卡死；无效依赖理想情况下不额外重取，现有实现若多重取应记录为性能问题。实际分支目标在同周期修正中优先。
- **意义：** 分开功能错误与无意义等待；验证不同指令年龄下的控制优先级。

### V05 · store 的两个源依赖

- **输入：** ALU→sw 写数据、ALU→sw 基地址、load→sw 写数据、load→sw 基地址各一例；地址放在有效 RAM 内。
- **观察：** ID 两个读口、EX reg2_rd_data、B MEM_BUFFER、mem_wr_addr_o/data_o/en_o。
- **通过：** 只有目标地址发生一次预期写入，数据正确；错误路径 store 不可落入 RAM。
- **意义：** store 虽无 rd 写回，仍是双源消费者并有不可忽略副作用。

### V06 · 同址 store→load 与连续部分写

- **输入：** sw 后紧邻 lw 同地址；两个连续 sw 同地址再 lw；初始字 0x11223344，在 offset 1 执行 sb 0xAA，再在 offset 2 执行 sh 0xBBCC。
- **观察：** 写缓存地址／使能、B 当前写优先级、RAM wrapper 同拍旁路、读返回寄存、低位选择。
- **通过：** 最新写值可见；部分写最终 word 为 0xBBCCAA44，未写字节保持。每个时钟边沿检查返回与控制的指令归属。
- **意义：** 覆盖读改写与同拍过程；B 阻塞赋值应单独审查，并对任何编码修改做前后语义比较。

### V07 · 容量、边界和 load 扩展

- **输入：** 在 0x80100000 与 0x80110000 写不同 word 后读回；读写窗口最后一个字与字节；用 0x80、0x8001 比较 LB/LBU、LH/LHU。
- **观察：** bridge 译码、RAM 地址切片、funct3、对齐地址、读数据符号位。
- **通过：** 地址行为与正式约定一致；若 A 当前发生别名应报告事实并明确支持窗口。LB 0x80 应得 0xFFFFFF80，LBU 应得 0x00000080；半字同理。
- **意义：** 容量配置与系统可见映射不是同一个概念。非对齐访问需另定异常或限制契约，不强行要求当前核支持。

### V08 · 分支依赖和错误路径副作用

- **输入：** ALU→branch、load→branch；实际跳／不跳组合；错误路径安排写 GPR 与 sw；连续条件分支。
- **观察：** branch 在 ID 的操作数、EX 实际方向与目标、延迟预测、IF/ID 和 ID/EX 清空。
- **通过：** 寄存器与内存最终结果符合顺序执行；错误路径无副作用，后端较老指令不被误杀。
- **意义：** 正确性与罚拍分开检查，精确罚拍用同条件正确预测路径作对照。

### V09 · 预测表训练、别名和目标错误

- **输入：** 同一循环 TTTN、交替 TN、两分支相关序列、相同低位索引的不同 PC；在独立可扩展配置中覆盖 bit14=1；受控注入错误 BTB 目标作为故障实验。
- **观察：** 原预测 PC、方向、目标、索引；GBHR/GBHR_old；PHT/CPT 更新地址与值；B 延迟训练端。
- **通过：** 更新对应原分支；计数饱和正确；CPT 仅向胜出者调整；目标错配能恢复或明确暴露当前缺口。原始 16 KiB 配置无法执行的地址实验必须标记为修改配置后的实验。
- **意义：** 原始方向、最终门控方向、BTB miss 和目标错必须分开统计。

### V10 · 复位、计数器和跨频率协议

- **输入：** 在不同相位释放复位；CPU 连续发 counter 启停写；在有效支持范围内改变请求相对 50 MHz 边沿的时刻；虚拟 IO 连续变化。
- **观察：** PLL locked 的使用、各域复位、start、cnt_wen、cnt_ms、跨域数据一致性。
- **通过：** 每个约定请求准确处理，复位后无错误写入，快域脉冲不丢失，多位状态无撕裂。周期仿真不能模拟真实亚稳态，还需关系／CDC 分析。
- **意义：** 同源时钟相关性、协议可靠性和物理亚稳态是不同问题。

### V11 · 完整时序约束与实现复现

- **输入：** 固定源码、IP、器件、工具版本、初始化、约束与运行策略；先解决历史覆盖缺项的来源。
- **观察：** no_clock、未约束端点、I/O delay、时钟关系、setup/hold、关键路径和 utilization；逐项解释合法例外。
- **通过：** 引用完整、功能基线通过；所有时序覆盖项有依据，不能仅凭 WNS 正号通过。记录新报告与 commit／输入哈希。
- **意义：** 这一步属于未来综合／实现，本次明确未执行；也不能承诺历史结果原样复现。

### V12 · 性能与优化因果

- **输入：** 同任务固件、编译选项、RAM 容量和实现策略；在功能正确前提下分别比较 A/B 及可行的单变量改造。
- **观察：** 完成指令数、周期、重取／冲刷、方向和目标错误、实际配置频率、资源。CoreMark 需补齐可核验固件、校验输出与计时口径。
- **通过：** 原始日志能复算指标；不把各版本多变量差值归给单个模块；报告执行时间而非仅最高主频。板卡功耗如需比较，应另做同负载电源测量。
- **意义：** 回答“优化是否真的改善任务时间”，而不预设 B 必须胜出。
